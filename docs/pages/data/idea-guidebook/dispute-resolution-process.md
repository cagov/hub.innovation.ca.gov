<p class="text-lead">Use this process if:</p>

* The Data Provider objects to the data exchange
* You disagree on how to de-identify data
* You disagree on costs

The process resolves issues at the lowest level possible.

1. Are both the Data Provider and Data Recipient under the Governor's authority?
    * Yes: Go to step 2.
    * No: Go to step 3.
2. Have your agency chief data officers mediate the dispute. 
    * If an agency doesn’t have a chief data officer, involve their agency information officer.
    * If you resolve the dispute, finalize the BUCP and submit it using the [BUCP Inventory Form](https://airtable.com/appBDfkcteQhHoKBG/pag8eHPdioJyEW8uk/form).
3. Have the Data Provider and Data Recipient write down their perspectives.
    * If you resolve the dispute, finalize the BUCP and submit it using the [Dispute Mediation Request Form](https://airtable.com/shrWblGAAafhXPBFb).
4. The Statewide Chief Data Officer will hold meetings to mediate.
    * If you resolve the dispute, finalize the BUCP and submit it using the [BUCP Inventory Form](https://airtable.com/appBDfkcteQhHoKBG/pag8eHPdioJyEW8uk/form).
5. What happens next depends on if the Governor’s authority applies.
    1. If both are under the Governor's authority, the Chief Data Officer will recommend a decision. The Governor's office will approve or deny it.
    2. If one or more are not under the Governor's authority, the BUCP is not approved.

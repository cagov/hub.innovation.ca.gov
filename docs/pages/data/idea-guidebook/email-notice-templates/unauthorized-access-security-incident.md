Subject: Notice of [unauthorized access to/security incident involving] data shared under IDEA

Dear [Data Provider contact name],

Our departments signed the State of California’s [Interagency Data Exchange Agreement (IDEA)](/data/idea-guidebook/). It’s a memorandum of understanding to help state entities share data.

Under IDEA, we negotiated the attached business use case proposal for you to share [briefly describe the data].

[For unauthorized access: We experienced an instance of unauthorized access. {Brief description of unauthorized access}.
We are reviewing the access to identify fixes and stop future unauthorized access.]

[For security incident: We experienced a security incident related to this data. {Brief description of the incident. Consider attaching a detailed report}.]

Let us know if you need more information or want to meet.

[Your signature]

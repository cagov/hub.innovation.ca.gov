<p class="text-lead">Use this email template to start a conversation about making a data sharing agreement.</p>

Subject: Request to share data under IDEA

Dear [Data Provider contact name],

Our departments signed the State of California’s [Interagency Data Exchange Agreement (IDEA)](/data/idea-guidebook/). It’s the state’s umbrella memorandum of understanding to help state entities share data.

We would like to get the following data from your department through the IDEA: [Brief description of data and purpose]

When can we meet to review this request? If there’s a better contact for this, let us know who we should talk to.

[Data Recipient signature]

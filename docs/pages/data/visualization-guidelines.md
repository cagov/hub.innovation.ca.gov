<p class="text-lead">Data visualization uses charts, maps, tables, and other visuals to make data easier to understand and use.</p>

Use this toolkit to create clear and accessible visualizations or improve existing ones. Choose what best describes your need to get started. If you’re new to data visualization, try working through the toolkit in order.

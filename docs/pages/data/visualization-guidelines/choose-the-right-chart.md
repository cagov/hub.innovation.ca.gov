## Start with relationships. Simple is better.

Before choosing a chart, identify the relationship in the data you want to show. We outline common relationships you might encounter below. 

Start simple. Add complexity only when it earns its place. For a general audience, use familiar charts such as bar, line, column, and pie charts. Use less common chart types only when they communicate the data more clearly. For example, treemaps, slope charts, box plots, and streamgraphs.

### [Chart alternatives: should I use a chart at all?](/data/visualization-guidelines/choose-the-right-chart/chart-alternatives)

* Key performance indicators
* Statistic with icon
* Progress bar
* Data table

### [Comparison: how do these items compare?](/data/visualization-guidelines/choose-the-right-chart/comparison)

* Bar charts
* Grouped bar charts

### [Part-to-whole: what share of the total is this?](/data/visualization-guidelines/choose-the-right-chart/part-to-whole)

* Stacked bar charts
* Tree maps
* Waffle (or grid) charts
* Pie charts
* Donut charts

### [Change over time: how has this changed?](/data/visualization-guidelines/choose-the-right-chart/change-over-time)

* Line charts
* Area charts
* Slope charts

### [Geographic: where is this happening?](/data/visualization-guidelines/choose-the-right-chart/geographic)

* Choropleth maps
* Dot/bubble maps
* Symbol maps

### [Relationships: are these items connected and how?](/data/visualization-guidelines/choose-the-right-chart/relationships)

* Scatterplot
* Bubble chart

### [Distribution: what's the spread?](/data/visualization-guidelines/choose-the-right-chart/distribution)

* Histogram
* Scatterplot
* Bar chart with error bars
* Box plots

The Financial Times' [Visual Vocabulary](https://github.com/Financial-Times/chart-doctor/blob/main/visual-vocabulary/README.md) has more chart types and relationships.

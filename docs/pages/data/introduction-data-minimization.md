<p class="text-lead">This online, self-paced course covers how to collect and share information responsibly.</p>

The course starts with core data privacy and minimization principles. You’ll learn how to:

* Use best practices to protect sensitive data
* Conduct risk and necessity assessments to find and remove unneeded data
* Handle external data requests
* Share data safely
* Review vendor contracts to make sure suppliers meet state privacy expectations
